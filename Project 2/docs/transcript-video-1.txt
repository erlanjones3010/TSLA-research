[0:00] Hello, my name is Erlan Jones, and this is Project 2, Video 1 for FIN
43900, Financial Applications. I used Claude and Codex to help build, run and
debug this app, but the analysis and decision are my own. Also, this is
education, not investment advice.

[0:23] This app manages the Meridian endowment from Lab 13. It's $100 million,
pays out $750,000 a quarter, and needs to earn inflation plus 4%, or 6.5%. It
compares three portfolios, equal weight, a 60/40 benchmark and a constrained
portfolio, using one signal: the 10-year Treasury yield as it was known on each
date.

[0:47] Going back to VS Code and the app from Lab 15: how my system changed. In
Labs 14 to 17, I built separate pieces: an optimizer, an as-of data rule and a
mandate checker. For this project, I first combined them using a mandate I made
up myself. Then I reread the project brief and saw it requires my Lab 13
mandate, so I rebuilt the rules to match it. Every rule is now tagged S1 to S10,
and the optimizer picks the lowest-risk mix that still reaches 6.5%, the same
idea as my Lab 14 work.

[1:19] Going to GitHub and my locked prediction: how my thinking changed. I ran
a locked test. I raised the equity premium from 4% to 5% and committed my
prediction to GitHub before running it. Here's the commit with the timestamp. I
predicted SPY would rise from 60% to 70%, because stocks would look more
attractive.

[1:39] When I moved the slider in the app to 0.05, it did the opposite: SPY fell
to 45%. The model minimizes risk while reaching 6.5%, so when stocks are
expected to earn more, it needs less stock to hit the target. I was thinking
like a return maximizer. This change came from my own analysis; the test showed
me how the rule actually works.

[2:04] Going back to GitHub: one AI output I checked. Codex wrote the chart code
with the width setting. When I ran the app on my Mac, it crashed with this
error, because my Streamlit version doesn't support that setting. I corrected
it: the code was changed to a setting my version supports, and I reran the app.
Here's the same chart working. I didn't accept the AI code until it worked on my
machine, so I double-check everything and make sure it runs before I rely on it.

[2:39] What I learned: the rules in the mandate decide how the model reacts, and
I test AI output myself before I trust it, because otherwise it could fail.
Thank you.
